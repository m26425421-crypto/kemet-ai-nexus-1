## نطاق العمل

هذا التوسع ضخم جداً (Marketplace كامل + 25 وكيل AI + Workspace سحابي + Fitness + 30 لغة + نظام كريدت/إعلانات ديناميكي). تنفيذه كله في دفعة واحدة سيؤدي إلى صفحات سطحية. أقترح تقسيمه إلى 5 دفعات، وسأبدأ بالدفعة 1 فور موافقتك، ثم أنتظر تأكيدك بعد كل دفعة.

## الأساس المشترك (يُنفَّذ في الدفعة 1 قبل أي ميزة)

1. **جدول `app_settings` موسّع** — إضافة كل الأسعار الجديدة (TTS/دبلجة/صور/فيديو/شعار/Thumbnail/OCR…)، حدود الإعلانات اليومية لكل قسم، عتبة الأخطاء في اللغات، عمولة المتجر، وتفعيل/تعطيل كل قسم رئيسي.
2. **دالة `spend_or_watch_ad` موحّدة** — تتحقق من الرصيد، وإلا تُرجع عدد الإعلانات المطلوبة (1 أو 3 حسب التكلفة)، مع عدّاد يومي لكل قسم (10 حد أقصى) في جدول `ad_watch_daily`.
3. **Hook `useSettings()`** — يقرأ `app_settings` مرة واحدة ويوزّعها على كل الشاشات (Home/Images/Videos/Store) فينعكس أي تغيير من الأدمن فوراً.
4. **صفحات الميزات الفعلية فقط** — لا صفحات فارغة. أي قسم غير جاهز يُخفى تلقائياً عبر `features.*` في `app_settings`.

## الدفعة 1 — الأساس + Marketplace (الآن)

- ترحيل قاعدة البيانات:
  - `marketplace_products` (بائع، نوع، سعر، وصف، فئة، كلمات مفتاحية، صور، ملف، حالة موافقة).
  - `marketplace_orders` (مشتري، منتج، مبلغ، عمولة، حالة).
  - `marketplace_reviews` (نجوم، تعليق).
  - `marketplace_favorites`, `marketplace_follows`.
  - `seller_payouts` (سحوبات، حالة).
  - `ad_watch_daily` (user_id, section, date, count).
  - RLS كاملة + GRANT.
  - RPCs: `mp_create_product`, `mp_purchase`, `mp_add_review`, `mp_request_payout`, `spend_or_watch_ad`, `record_ad_watch`.
- واجهات:
  - `/marketplace` — تصفح + بحث + فلترة بالفئة/السعر.
  - `/marketplace/$id` — تفاصيل + مراجعات + شراء.
  - `/marketplace/sell` — نشر منتج (المستخدم).
  - `/marketplace/dashboard` — أرباح البائع + سحوبات.
  - `/admin` — تبويب Marketplace (موافقة/رفض/عمولة/سحوبات).
- تكامل نظام الكريدت الجديد + الإعلانات المكافئة في `images.tsx` و`videos.tsx` كنموذج.

## الدفعة 2 — Agents + Workspace

- جدول `ai_agents` (قابل للتحرير من الأدمن) + جدول `agent_conversations` + شاشة `/agents` + شاشة محادثة لكل وكيل تستخدم نفس بنية `/chat`.
- `/workspace` — عرض موحّد لكل المحتوى (محادثات/صور/فيديو/ملفات) مع مجلدات (`workspace_folders`)، بحث، مفضلة، إعادة تسمية.

## الدفعة 3 — Fitness

- جدول `exercises` (عضلة، نوع، فيديو، شرح، معدات) + `workout_plans` + `nutrition_logs`.
- شاشة استبيان (عمر/طول/وزن/هدف) → توليد برنامج عبر AI Gateway + حفظه.
- تتبع سعرات/ماء/خطوات/نوم + تقرير أسبوعي.

## الدفعة 4 — Languages

- `languages` (30 لغة seeded) + `lessons` + `lesson_stages` + `user_progress` (XP، شارات، مستوى، أخطاء يومية).
- شاشات: قائمة اللغات → دروس → مراحل تفاعلية (اختيار/كتابة/استماع عبر Browser TTS، نطق عبر STT).
- منطق: عند الوصول لعتبة الأخطاء (من `app_settings`) → إعلان إجباري + تصفير + احترام سقف 10/يوم.

## الدفعة 5 — تلميع + Admin شامل

- تبويبات أدمن جديدة: Marketplace، Agents، Languages، Fitness، Ads limits.
- إحصائيات موسّعة (مبيعات، أرباح، طلبات سحب معلّقة، أكثر اللغات نشاطاً).
- تحسين أداء (lazy load للأقسام الثقيلة)، مراجعة استهلاك الشبكة والبطارية، PWA offline لأهم الشاشات.

## ملاحظات تقنية

- كل الأسرار تبقى في السيرفر (`process.env` داخل `createServerFn`) — لا مفاتيح في العميل.
- المتجر لا يشمل بوابة دفع الآن (Paddle/Stripe) — الشراء يخصم من الكريدت، والسحوبات تُسجَّل كطلبات يوافق عليها الأدمن يدوياً. عند رغبتك بالنقود الحقيقية أُفعّل Paddle في دفعة منفصلة.
- AdMob جاهز مسبقاً في `src/lib/admob.ts` — سأربط `showRewardedAd()` بمنطق `spend_or_watch_ad` مباشرة.
- كل الميزات تُخفى تلقائياً إن كان `features.<name>=false` — لا أزرار ميتة.
